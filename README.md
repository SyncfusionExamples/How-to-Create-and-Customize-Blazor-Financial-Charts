# How to Create and Customize Blazor Financial Charts

Blazor samples demonstrating financial chart types and basic customization.

A quick start Blazor project that helps you learn how to add Blazor financial charts to a Blazor WebAssembly app. The samples show how to render chart types such as highlow, openhighlowclose, and candle with built-in features. You will also see how these charts visually indicate stock price variations using data elements like high, low, open, close, and volume.

**Example**: https://blazor.syncfusion.com/demos/chart/hilo  

**Documentation**: https://blazor.syncfusion.com/documentation/chart/chart-types/high-low 

## Project Overview

Contains Blazor samples demonstrating financial chart rendering. The code shows binding sample stock data and adjusting chart visuals.

## Features

- High/Low chart sample
- Open-High-Low-Close (OHLC) sample
- Candle (candlestick) sample
- Visual indicators for high, low, open, close, and volume

## Prerequisites

- Visual Studio 2022

## How to run the project

1. Checkout this project to a location on your disk.
2. Open the solution file using Visual Studio 2022.
3. Restore NuGet packages by rebuilding the solution.
4. Run the project.

## Usage

Open sample pages to view charts and inspect how data is bound and options are set.
